# 台股量化研究儀表板

以台灣證券交易所（TWSE）及櫃買中心（TPEx）公開收盤資料為主的本機研究工具。它會自動找出最近一個有資料的交易日、計算主流族群熱度，並提供個股的基本面、技術面與籌碼面摘要。

## 啟動

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python run.py
```

## 方法與限制

- 日行情與估值來自 TWSE/TPEx 公開 API；個股歷史、財報及法人交易以 `yfinance` 作補強，可能有延遲、缺漏或代碼覆蓋限制。
- 主流族群依產業的成交值、上漲家數比例、平均漲幅和量能相對強度排序，並非預測。
- 族群顯示使用中文官方產業名稱；常用的細分主題（目前含被動元件）會覆寫較寬的官方產業分類。
- 「法人／月線選股」要求投信連續 3 個交易日買超、月線（20 日）上方連續強勢或強勢後回測月線 ±3%。「主力」並非官方標準資料欄位，因此以成交額與正向漲幅的價量參與代理，畫面會清楚標示。
- 族群可展開檢視全部個股，並標示 TAIFEX 個股期與 TWSE 權證是否存在。個股籌碼頁列出近 10 個可得交易日的外資、投信、自營商及合計買賣超（上市）。
- 綜合分數是可檢驗的規則型研究訊號（基本面 30%、技術面 45%、籌碼面 25%），不是買賣指令。
- 使用前請自行驗證資料與回測；不含交易成本、滑價、除權息調整與個人風險承受度，不能視為投資或股期交易建議。
